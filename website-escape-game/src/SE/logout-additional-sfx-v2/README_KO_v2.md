# 추가 효과음 v2

문제 제기된 효과음만 새로 만들고, 합격된 게임 효과음 5개는 원본 그대로 유지했습니다.

- 보물상자: 걸쇠 → 낡은 경첩의 끼익 소리 → 나무 뚜껑 멈춤
- 우물: 회복 마법음 없이 짧은 물 튀김
- 불 끄기: 짧은 치익/증기 소리
- 시작 휘슬: 공기와 피 트릴이 섞인 실제형 심판 휘슬
- 관중: 20초 무한 루프, 비주기 목소리·박수·경기장 잔향
- 골: 휘슬과 UI음 없이 공·골망·관중 함성
- 공 접촉: 받기와 차기에 공용으로 쓰는 짧은 신발-공 접촉

모든 파일은 44.1kHz / 16-bit / mono WAV입니다.
